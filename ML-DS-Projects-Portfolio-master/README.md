# ML & DS Projects Portfolio

This repository contains a curated collection of Machine Learning (ML) and Data Science (DS) projects implemented using Python and Jupyter Notebooks. The goal of these projects is to apply data-driven techniques to real-world problems and build practical experience with ML algorithms, data preprocessing, model evaluation, and exploratory data analysis (EDA).

## 📁 Project Structure

### ✅ Machine Learning Projects:
- *Linear Regression*: Predictive modeling using Boston housing dataset.
- *Logistic Regression*: Classification problem solving.
- *Support Vector Machine (SVM)*: Classification with breast cancer data.
- *Decision Trees*: Classifier models with purchasing datasets.
- *K-Means Clustering*: Unsupervised learning for data grouping.
- *LDA for Dimensionality Reduction*: Preprocessing for high-dimensional data.

### ✅ Data Science Workflows:
- *EDA Notebooks*: Visual exploration and preprocessing of datasets (e.g., iris, mobile prices).
- *Shell Code Notebook*: Template for automation or command-line integration.

## 📊 Datasets Used
- *Iris Dataset*
- *Mobile Price Dataset*
- *Breast Cancer Dataset*
- *Boston Housing Dataset*
- *Custom CSVs for Purchase and Classification Tasks*

## 🛠 Tools & Libraries
- Python (Jupyter Notebooks)
- NumPy, Pandas, Matplotlib, Seaborn
- Scikit-learn
